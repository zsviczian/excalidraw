## Remaining risk-based coverage

The highest-probability regression is selection changing an active text/crop/line-editing session or drag state, especially in a popout. Physical phone/tablet shift-equivalent gestures, touch context menus, pen interactions and crop handles need separate device validation. Windows/Linux, application cold restart, restored popouts, signed/multi-element resize and broad old-scene/export coverage are not established by a macOS CLI run. Source/build and synthetic owner-window probes do not replace physical touch evidence. Package publication and a durable plugin dependency update remain separate maintainer release work.
